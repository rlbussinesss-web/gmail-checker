⚡ INÍCIO RÁPIDO
─────────────────────────────────────────────────────────────

1. Certifique-se que tem Node.js instalado:
   https://nodejs.org/ (baixa versão LTS)

2. Clique duplo em: INICIAR.bat

3. Aguarde e abra: http://localhost:3000


🎯 O QUE FAZ
─────────────────────────────────────────────────────────────

✅ Testa credenciais de email automaticamente
✅ Tenta múltiplas senhas na mesma aba (rápido!)
✅ Testa vários emails simultâneos (5 de uma vez)
✅ Exporta resultados em JSON ou CSV
✅ Dashboard com estatísticas completas
✅ Logs detalhados de cada tentativa


📋 FUNCIONALIDADES
─────────────────────────────────────────────────────────────

[Individual] - Testa um email com uma senha
[Em Massa]  - Testa múltiplos emails de uma vez
[Estatísticas] - Vê todos os resultados
[Senhas] - Adicione suas próprias senhas

🔐 TESTES DE SEGURANÇA
─────────────────────────────────────────────────────────────

- Abre navegador automaticamente
- Simula login real no Gmail
- Detecta senha correta quando login sucede
- Tenta próxima senha se falhar
- Salva APENAS senhas que funcionaram


💾 DADOS SALVOS
─────────────────────────────────────────────────────────────

results.json - Todos os emails + senhas funcionando
custom_passwords.json - Senhas que você adicionou
logs.json - Log detalhado de tudo


📊 EXPORTAR DADOS
─────────────────────────────────────────────────────────────

1. Clique em "📊 Estatísticas"
2. Clique em "📥 Exportar JSON" ou "📥 Exportar CSV"
3. Arquivo baixa automaticamente


⚠️ IMPORTANTE
─────────────────────────────────────────────────────────────

- Use apenas com autorização
- Não teste emails de outras pessoas sem permissão
- Mantenha os resultados em local seguro
- Limpe dados sensíveis quando terminar


❓ PROBLEMAS
─────────────────────────────────────────────────────────────

Programa não abre?
→ Instale Node.js: https://nodejs.org/

Porta 3000 já em uso?
→ Encerre outros programas que usam porta 3000

Navegador não abre?
→ Abra manualmente: http://localhost:3000
